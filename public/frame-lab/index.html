01.收集视觉参考
每次收集 5–10 个同类客户端，记录它们的共同规则而不只是保存截图。
02.拆分设计 Token
提取背景、前景、边框、强调色、间距、圆角、阴影以及字体层级。
03.搭建 Figma 结构
先搭 Auto Layout 骨架，再用可复用组件和变量填入视觉细节。
04.移植到客户端
在 Tauri / WPF 中复现并测试窗口缩放、键盘操作、密度和性能。
