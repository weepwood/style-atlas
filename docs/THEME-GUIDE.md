# 新增主题设计手册 · Style Atlas (2026-10-11)

## 收录策略

主题既要有可辨识的材质、色彩和排版语法，也要有对应的**应用场景、风险和实现方式**。不从真实产品擅自复制受保护的资源；示例全部用 React 与 CSS 组合，不宣称官方样式或 1:1 复刻。

## 原有主题的细化方向

- **Glass / Aurora / Neumorphism / Clay**：合理区分透明、柔焦、浮雕和体积光，不将材质特点应用于所有容器。
- **Bento / Swiss / Editorial**：以栅格尺寸、信息权重和版面空白决定排布，弱化通用卡片模板感。
- **Brutal / Bauhaus / Memphis / Cyber**：硬边框、几何构造和局部高饱和强调遵循统一网格，避免靠长时间运动获得存在感。
- **Organic / Zen / Luxury / Academia**：通过字体细节、色彩阶梯和间距表达气质，减少浮动装饰。
- **Y2K / Vaporwave / Pixel**：展示其媒介符号和文化语境，统一比例并降低频闪风险。
- **Terminal / Material**：优先清晰的状态、控制层级、响应性和可访问性。

统一的全站 Token 放在 `src/styles/theme-refinements.css`，新增的独立缩略预览放在 `src/styles/new-style-previews.css`。每个新增主题必须同时拥有数据和组件实现，新增了案例也要更新详情、交互评估及移动端质量检查。

## 开发约定

1. 在 `src/data/newStyles.ts` 添加结构化案例数据（id、分类、palette、tokens、风险）。
2. 在 `src/components/NewStylePreview.tsx` 加入独立的布局，不只替换渐变色。
3. 编写一套 `.preview-<id>` 的主题缩略样式，以及一套 `html[data-atlas-theme="<id>"]` 全站主题规则。
4. 在 `src/components/StylePreview.tsx` 登记新 ID；自动进入卡片、详情、收藏、搜索和主题切换。
5. 测试交互和减少动画选项，并更新动效建议文件。
